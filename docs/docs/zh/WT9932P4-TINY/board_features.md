## 简介

启明云端 `TINY` 开源开发板系列中的 `WT3299P4-TINY`，是一款基于乐鑫 `ESP32-P4` 的纯单片机开发板，专注于小巧轻量的应用场景。`ESP32-P4` 是乐鑫推出的新一代高性能、低功耗 `MCU`，采用双核 `RISC-V` 处理器，主频最高可达 `400MHz`，集成了丰富的外设与接口资源，支持 `USB 2.0 OTG`、`MIPI CSI/DSI`、`SDIO`、以太网、`CAN FD` 等高速通信，同时内置 `AI` 加速器与图形加速引擎，可胜任语音识别、图像处理与边缘计算等复杂任务。其灵活的存储扩展方案兼容 `PSRAM`、外部 `Flash` 以及大容量内存映射，适合多任务和大型应用的开发。`WT3299P4-TINY` 的设计初衷是帮助开发者快速上手 `ESP32-P4`，在开源生态中提供一款高性价比、体积小巧且易于学习与实践的开发平台。

---

### 🔧 核心硬件配置

- **核心模组**：开发板采用启明云端 WT0132P4-A1 模组，该模组集成了 DCDC 电源、晶振和 Flash 等核心功能，极大地简化了外围电路设计，使得开发板仅需两层板即可完成设计。
- **MIPI 接口**：开发板引出了 MIPI CSI 与 MIPI DSI。接口使用树莓派同线序的接口，方便后续的屏幕和摄像头开发。
- **SD 卡接口**：开发板背面支持四线 SDIO。用户可以自行焊接后使用四线 SD 卡接口。方便用户使用 SD 卡。

---

### 🛠️ 设计特点

1. 核心配置：以高性能乐鑫 ESP32P4 芯片为核心，满足嵌入式开发性能需求。
2. 紧凑尺寸：仅 69x28mm 的小巧规格，适配空间受限的应用场景。
3. 稳定设计：基于 WT0132P4‑A1 模组打造，采用两层板设计，保证稳定性同时降低成本。
4. 图像接口：板载 MIPI DSI 和 CSI 的 FPC 接口，支持显示输出与图像采集功能。
5. 扩展灵活：全部引脚引出，排针支持面包板连接，方便扩展外设。
6. 状态指示：配备板载 RGB 灯，可实现多彩状态指示与交互效果。
7. 便捷接口：搭载 Type‑C 接口的 FUSB 和 HUSB，传输快速且支持正反插，便于调试与供电

## 电源特性

可以从以下供电方式中任选其一给 `WT3299P4-TINY` 系列开发板供电：
- 通过 `FUSB` 接口外接供电；
- 通过 `HUSB` 接口外接供电；
- 找到 `5V` 电源输入口，采用杜邦线连接对应电压；
